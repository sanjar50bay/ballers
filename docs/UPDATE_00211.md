# BALLERS 0.2.11 — приветственная страница и первое знакомство

## Изменения
- Вместо пустого входа — согласованная страница «Твой футбол. Твоя история.»: объяснение продукта, три шага, повторный Google CTA.
- Текст учитывает готовые команды: «Найди свою команду или присоединяйся к играм. Уже есть команда? Собери её в BALLERS и организуй свою игру.» Это не обязательный выбор постоянной роли.
- Русский/Қазақша, видимый переключатель. Сохранённый выбор имеет приоритет; на первом посещении — основной язык браузера (kk → қазақша, остальные → русский). Город и геолокация язык не определяют. Английский не добавлен.
- Оригинальные RU/KK MP4 включены локально, без стороннего хостинга. Обложки, кнопка воспроизведения, штатные пауза/громкость/полноэкранный режим. `preload=none`, без автоматического запуска/звука. При смене языка прежний плеер останавливается, следующий ждёт нажатия. Оба ролика сразу не скачиваются.
- Видео доступно после регистрации в существующей помощи «?». Обучение с подсветкой сохранено.
- Baller ID предлагается автоматически только после подтверждённого нового INSERT профиля, а не при каждом входе. Сразу можно закрыть. Таймер и 30-минутный повтор убраны. Ручной показ остаётся в профиле без автозакрытия. Устаревшая настройка повторного показа удалена.
- Метка первого показа — в sessionStorage текущей вкладки, подтверждение показа — в localStorage профиля. Сбой хранилища/неопределённый ответ записи не блокируют вход: карточку можно открыть вручную. Это не новая серверная межустройственная настройка. Существующим пользователям карточка не навязывается.
- OAuth-функция и переходы по приглашениям сохранены. Никаких новых разрешений или SQL.

## Важное про исходные видео
В обоих оригинальных роликах остаётся рассказ о подтверждении капитанами. Под плеером есть локализованное уточнение: по умолчанию результат учитывает ведущий, подтверждение капитанами — отдельный строгий режим. Сами ролики и озвучка не редактировались. Их обновление — отдельная задача; этот релиз не выдаёт старый фрагмент за обязательный текущий процесс.

## Установка поверх вашей 0.2.10
**Нового SQL нет. В SQL Editor ничего запускать не нужно. Миграции 001–008 не повторять.**
1. Сделай резервную копию рабочей папки. Распакуй архив отдельно в `Музыка\ballers-alpha-0.2.11`.
2. Открой PowerShell в новой папке и скопируй исходники штатным скриптом:
```powershell
powershell -ExecutionPolicy Bypass -File .\UPDATE_EXISTING_PROJECT.ps1
```
3. Все следующие команды — в старой постоянной рабочей папке:
```powershell
cd "$env:USERPROFILE\Music\ballers-alpha-0.2.2"
npm ci
npm audit
npm run build
git status --short
git check-ignore .env.local
```
4. Посмотри новую страницу локально, выйдя из аккаунта либо в приватном окне:
```powershell
npm run start
```
Открой `http://localhost:3000`. Авторизованному пользователю по-прежнему показывается личная главная, а не лендинг. Проверь переключение языка и видео. Локальный реальный OAuth требует разрешённого callback в Supabase; тесты его не заменяют.
5. После проверки останови локальный сервер Ctrl+C, затем:
```powershell
git add .
git diff --cached --name-only -- ".env*" ".netlify"
git diff --cached --stat
```
Первая команда проверки секретных файлов должна дать пустой вывод. Только после просмотра состава изменений:
```powershell
git commit -m "Release 0.2.11: bilingual landing and first profile experience"
git push origin main
```
6. Дождись Published нужного коммита в Netlify. Проверь сайт в приватном окне; в обычном — сохранение входа и приглашения. Никакие commit/push/deploy этим архивом автоматически не выполняются.

## Что не входит
Новые рейтинги, достижения, друзья, арены, пенальти и LIVE-таблица. Доверенный режим 0.2.10 и права организатора/ведущего не изменены. Реальные пользователи и их данные не удалялись и не редактировались.
