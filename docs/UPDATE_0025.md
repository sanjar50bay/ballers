# Обновление BALLERS 0.2.5 — русский / қазақша и карточка игрока

Для текущей установки 0.2.4 с применённой миграцией 004. **Нового SQL нет. Baseline и миграции 001–004 повторно не запускать.** Аккаунты, команды, игровые дни и результаты сохраняются в прежней базе.

## Что меняется
- Общий переключатель «Русский / Қазақша» на всех 17 страницах, включая вход, регистрацию и приглашения. Язык переключается без выхода из аккаунта и сохраняется в этом браузере, в том числе до входа. При создании профиля выбор записывается в существующее поле preferred_language; редактирование профиля также сохраняет текущий язык. Между разными устройствами автоматическая синхронизация выбора этим релизом не добавляется.
- Переведены системные заголовки, кнопки, поля, позиции, роли, режимы команд, ошибки, уведомления, состояния загрузки и календарные названия. Имена игроков, названия команд/сообществ/игр, введённые адреса и комментарии пользователей не переводятся.
- Своя коллекционная карточка Baller ID: крупное реальное фото (или инициалы), фигурная двойная рамка, зелёное/фиолетовое/голубое свечение на чёрном фоне, лёгкий объёмный поворот и световой блик. Без чужих игровых ассетов, выдуманного рейтинга или незаработанных наград; только подтверждённая статистика.
- Автопоказ при возвращении на главную после 30 минут с последнего показа, в том числе при возвращении во вкладку. Интервал 30 минут — предложенное стартовое значение вместо «раз в день». Обычные переходы по разделам сами по себе не запускают показ. Старое отключение в профиле сохраняется. Показ закрывается нажатием, Escape или через 5 секунд.
- В профиле есть кнопка просмотра карточки. При reduced motion автоматический показ пропускается; ручной просмотр статичный.
- Чёрно-неоновая палитра и контраст полей приведены к общим правилам, в том числе на старых страницах создания и редактирования.
- Сохранены защиты первого создания профиля из 0.2.4: проверка собственной записи, блокировка двойной отправки, восстановление после потерянного ответа, отсутствие перезаписи существующей анкеты, свежая главная после сохранения, сохранение целевого приглашения.

## Установка без путаницы с папками

Git-папка проекта остаётся прежней: **Музыка\ballers-alpha-0.2.2**. Цифры в имени папки менять не нужно.

1. Скачай ZIP и распакуй рядом папку `ballers-alpha-0.2.5`.
2. Открой PowerShell в распакованной папке и выполни:

```powershell
powershell -ExecutionPolicy Bypass -File .\UPDATE_EXISTING_PROJECT.ps1
```

Скрипт проверит наличие `.git` в прежней папке и скопирует только исходники. Он не удаляет файлы, не копирует node_modules/.next/.git/.netlify, не трогает `.env.local`, не выполняет SQL, commit или push.

3. Открой PowerShell в прежней Git-папке `ballers-alpha-0.2.2`:

```powershell
npm ci
npm run build
git status
```

Проверь: `.env.local`, node_modules и .next не должны быть среди добавляемых файлов.

```powershell
git add .
git diff --cached --name-only
```

Если в списке нет секретных/сгенерированных файлов:

```powershell
git commit -m "Add Kazakh language and neon player card"
git push origin main
```

4. Дождись нового **Published** в Netlify. Настройки Next.js Runtime, publish `.next`, публичные Supabase-переменные и точечное исключение их имён из secrets scanning не менять.

## После публикации

- В приватном окне выбери Қазақша до входа → Google → первый профиль → главная; повтори с медленной связью и двойным нажатием. Завтрашняя проверка реальными пользователями остаётся обязательной: локальные тесты не проверяют настоящий Google OAuth/реальный Supabase.
- Пройди сообщества, создание дня, составы, игровой центр, приглашение, историю и редактирование профиля в обоих языках. Попроси казахоязычного участника проверить естественность формулировок.
- Переключи язык, обнови страницу, закрой и снова открой браузер без очистки данных — выбор должен остаться.
- Профиль → «Показать мою карточку». Проверь фото, реальные показатели, пропуск и отключение. Автопоказ не должен повторяться при каждом переходе на главную.

## Следующие этапы, не реализованные в этом пакете

1. Подтвердить первый вход реальными пользователями после исправления регистрации.
2. Постоянные команды: анкета ответственного, командная ссылка, присоединение игроков с собственными Baller ID.
3. Затем турниры, поиск команд, роли судей / Referee ID, арены и мероприятия.
4. Позже лента объявлений, вызовы команд, поиск игроков и тренеров.

Apple/VK по-прежнему требуют отдельной настройки провайдеров. Этот релиз не включает их автоматически и не показывает неподключённые способы входа.
