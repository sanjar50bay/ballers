BALLERS 0.2.13-alpha — карточка игрока

Карточка в профиле получила вертикальный фигурный щит по референсу:
фиолетовый фон, лаймовая двойная рамка, розовые линии, портрет, постоянный Baller ID,
имя, позиция, город и настоящие матчи/голы/ассисты/сейвы. Используется прежний
источник статистики; тестовые матчи не становятся реальными показателями.
Общий рейтинг пока обозначен прочерком. Нет выдуманной скорости или силы. Пока данные не загружены — прочерк.

Первое получение карточки: короткий выход и четыре вспышки частиц.
Повторное открытие из профиля: сразу готовая карточка; эффект по кнопке.
Эффекты можно пропустить без закрытия. «Продолжить»/«Скрыть» и Escape
работают сразу. При reduced motion эффекты отключены, при уходе со вкладки
останавливаются. Звука нет. Клик по содержимому не закрывает карточку.

Исправлено управление фокусом для нескольких кнопок: Tab/Shift+Tab
остаются внутри окна; закрытие возвращает фокус на кнопку открытия.
За модальным окном блокируется прокрутка, при закрытии восстанавливается.
Фото берётся из профиля; при ошибке загрузки остаются инициалы.

Миграций и изменений прав нет. Правило одного ведущего и опубликованные
игровые сценарии остаются в 0.2.12. Новая карточка готовится отдельно в PR.

Проверка: сетевые браузерные сценарии дополнены проверками настоящих
значений (включая 0), повтора/пропуска, клавиатуры, reduced motion,
фотографии/ошибки загрузки, длинного имени на казахском при 320px.
Сценарий новой регистрации проверяет однократный автоматический показ.
Браузер работает с изолированным PGlite и имитированным auth/HTTP.

Публикация: после просмотра preview объединить PR и дождаться production
Netlify. SQL применять не нужно. Откат — предыдущий deploy 0.2.12,
сохранённые профили и статистика не изменяются.
