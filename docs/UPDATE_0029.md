# BALLERS 0.2.9 — понятный старт и добровольные подсказки

## Что изменено
- В форме сообщества нет готового Wednesday Football: пустое обязательное название, нейтральные примеры и подписи каждого поля. Одно сообщество может играть в разные дни на разных площадках; календарь повторяющихся игр пока не добавлен.
- «Мест на игровой день по умолчанию» явно отделено от количества участников сообщества. В отдельном дне своя вместимость. Пустое значение — без лимита.
- Создание сообщества: одна серверная RPC без лишних предварительных запросов аккаунта, блокировка двойного нажатия, ограниченное ожидание. При потере ответа не повторяем запись автоматически: предлагаем проверить «Мои сообщества». Это не новая серверная гарантия идемпотентности между вкладками/перезагрузками.
- Помощь через «?» в шапке и добровольное обучение: профиль → общий каталог → запись на игру → уведомления. Подсветка, назад/далее/пропуск, Escape, клавиатура; обучение само не отправляет заявки. Если элемент не загрузился, через 8 секунд можно продолжить без него.
- Предложение обучения можно отклонить, повторно запустить через помощь. Прогресс хранится отдельно для аккаунта в этом браузере, не на сервере; при недоступном хранилище приложение остаётся доступным, но запоминание не гарантируется.
- Понятные переходы «Мои сообщества» / «Все сообщества», поиск команды ведёт сразу на вкладку команд. Параметр вкладки обновляется и при переходах внутри каталога.
- «В заявках» в статистике заменено на «Матчи в составе»: это записи в составе подтверждённых реальных матчей, а не ожидающие заявки и не сыгранные минуты.
- Единое локальное семейство шрифтов, поля от 16px, более читаемые второстепенные тексты; новые строки RU/Қазақша. Не требуется загрузка Google Fonts при сборке.

## Что НЕ меняется
Google-вход, Baller ID и история сохраняются. Нового SQL нет, права доступа не расширяются. Подтверждения результатов и раздельные реальные/тестовые матчи остаются как в 0.2.8. LIVE-предварительная таблица, друзья, достижения/баллы, пенальти, арены, новые аудиодорожки, лендинг с видео и новый режим автоматической карточки в этот пакет не входят.

Диагностика текущих данных уже показала все три сообщества разных авторов в общем каталоге. Этот пакет улучшает путь к каталогу, но не объявляет доказанной или исправленной неизвестную серверную причину прежних жалоб. Трудности реального Google-входа на телефонах требуют воспроизведения на конкретном устройстве.

## Установка поверх опубликованной 0.2.8
**SQL Editor не нужен. Миграции 001–007 повторно не запускать.** Для более ранней схемы сначала отдельная инструкция 0.2.8.

1. Сохраните копию рабочей папки. Распакуйте архив отдельно в `Музыка\ballers-alpha-0.2.9`.
2. PowerShell в новой папке:
```powershell
powershell -ExecutionPolicy Bypass -File .\UPDATE_EXISTING_PROJECT.ps1
```
Скрипт переносит исходники в прежнюю Git-папку, сохраняет `.git`, `.env*`, `.netlify`, ничего не публикует.
3. Затем все команды сборки и Git — в старой рабочей папке:
```powershell
cd "$env:USERPROFILE\Music\ballers-alpha-0.2.2"
npm ci
npm run build
npm audit
```
При ошибке остановитесь. Не применяйте `npm audit fix --force` автоматически.
4. После успешной сборки:
```powershell
git status --short
git check-ignore .env.local
git add .
git diff --cached --name-only -- ".env*" ".netlify"
git diff --cached --stat
```
`.env.local` должен игнорироваться, список секретных файлов должен быть пустым. Если это не так — не делайте commit/push.
```powershell
git commit -m "Release 0.2.9: guided start and clearer community forms"
git push origin main
```
5. Дождитесь успешной публикации соответствующего commit в Netlify. Сборка на компьютере сама не обновляет сайт.

## Короткий тест после публикации
- RU и Қазақша на телефоне: «?» → обучение → переходы/пропуск/повторный запуск, кнопки доступны, подсветка не мешает записи.
- Создать сообщество с собственным названием; проверить подсказку о местах и появление в «Мои сообщества».
- Другой аккаунт видит его в общем каталоге, но не получает управление чужим сообществом.
- Войти через настоящий Google, обновить страницу, открыть приглашение. Ничьи существующие аккаунты ради теста не удалять.

Локальные результаты и ограничения: `docs/VALIDATION_0029.md`. Сайт и рабочая база при подготовке архива не изменялись.
