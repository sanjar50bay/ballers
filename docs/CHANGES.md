Сохранены регистрация, матчи, карьера и карточка. RU/Қазақша на 22 страницах. Миграция 005, инструкция UPDATE_0026.md. ## 0.2.5-alpha — русский / қазақша и карточка игрока

Единые чёрно-неоновые поля и контраст старых экранов. SQL и зависимости не менялись. Защиты регистрации сохранены. Инструкция: UPDATE_0025.md.
