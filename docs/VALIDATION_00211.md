# Проверки BALLERS 0.2.11

## Стенд и ограничения
Локальная production-сборка Next.js 16.4.3, безопасный фиктивный URL/ключ Supabase. Chromium/Playwright и изолированная PostgreSQL/PGlite. Google OAuth и HTTP Supabase эмулированы; это не проверка настоящего Google-входа, мобильного Safari, живой Supabase, скорости мобильной сети или опубликованного Netlify. На рабочую базу запросы не отправлялись, публикация не выполнялась.

## Выполнено
- `npm ci --ignore-scripts`; `npm audit`: 0 уязвимостей.
- `npm run build`: production-компиляция и TypeScript успешны.
- `npm run lint`: 0 ошибок, 5 прежних предупреждений (неиспользуемые компоненты/изображения/зависимость эффекта).
- `npm test`: 129 прежних SQL/мобильных/навигационных проверок прошли; лог в `legacy.txt`.
- `npm run test:i18n`: 1056 полных пар RU/KK, статусы, даты, ошибки, 22 страницы подписаны на смену языка.
- 18 проверок SQL доверенного режима и 6 браузерных проверок: ведущий завершает без капитанов, исправления с историей, строгий режим отдельно, ограничения обычного участника сохранены.
- 12 UX-проверок предыдущего релиза: обучение, справка, каталог, форма сообщества, неопределённый ответ создания и казахский интерфейс.
- 11 новых браузерных сценариев лендинга: готовая команда учтена, оба CTA вызывают исходный OAuth; сохранённый язык важнее браузерного; RU/KK переключаются; ширины 320/390/768/1280 без горизонтального переполнения; видео не скачивается до нажатия, реально начинает играть после нажатия, при смене языка останавливается; MP4 byte-range; помощь; повторный вход без карточки; новый профиль с однократной карточкой без таймера; ручная карточка; возврат по ссылке команды.
- По 18 проверок регистрации на RU/KK прошли (всего 36): проверяют исходный профиль, гонку вкладок, потерю/таймаут ответа записи, ошибки доступа/валидации, сохранение приглашения и первый показ карточки. Итоговые логи — `registration-ru.txt` / `registration-kk.txt`.

Снимки страницы: `docs/landing-ru-390.png`, `docs/landing-kk-320.png`. Исходные видео не редактировались; старый фрагмент о капитанах пояснён под плеером. Субтитры/переозвучка в этот релиз не входят.

## Перед публикацией и после неё вручную
Проверить настоящий вход Google на двух телефонах, приватное и обычное окно, смену языка/видео, возврат по приглашению после OAuth, запуск видео со звуком на iOS/Android. На личной главной авторизованного пользователя лендинг не показывается — для просмотра выйди либо используй приватное окно. Убедиться, что Published в Netlify соответствует новому коммиту.
