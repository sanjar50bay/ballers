BALLERS — 0.2.11 + вход по коду на почту
Подготовлено 17.11.2026. Это исходники для проверки и сборки, не опубликованный deploy.

Основа: переданный BALLERS_alpha_0.2.11.zip.
Сохранены лендинг RU/KK, оба оригинальных видео, помощь с видео,
однократная карточка после нового профиля и ручная карточка в профиле.
Добавлены email-код и Google в единой форме, сохранение цели приглашения,
короткая регистрация, раскрываемые пояснения и статистика, приоритет игры
на личной главной. Логотип добавлен в метаданные ссылок; значок B — для вкладки.
Next.js и eslint-config-next обновлены с 16.4.3 до 16.4.6: устранено
предупреждение сборки об уязвимой версии Next.js. Остальные зависимости
не обновлялись специально; package-lock.json включён.

НОВОГО SQL НЕТ. baseline и миграции повторно не запускать.
Папки node_modules, .next, .git и приватные env в пакет не включены.
Файлы Downloads и исходные архивы не менялись. Старый патч для 0.2.10
поверх этой версии не применять.

Для тестового deploy в Netlify:
1. Сохранить текущий рабочий commit/deploy для возврата.
2. Перенести эти исходники в отдельную ветку текущего репозитория,
   сохранив его .git и приватную конфигурацию. Новый ZIP сам сайт не меняет.
3. Оставить действующие NEXT_PUBLIC_SUPABASE_URL и
   NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY нужного проекта.
4. Для deploy с email-кодами задать NEXT_PUBLIC_AUTH_EMAIL_ENABLED=true
   и выполнить новую сборку. Без флага форма показывает Google.
5. Node.js 24: npm ci, npm test, npm run lint, npm run build.
6. Проверить preview, затем опубликовать согласованный commit.

SMTP и шаблоны Magic link / Confirm sign up сохранены отдельно в Supabase.
SMTP-пароль находится только там; в браузерные env его не добавлять.
До приглашения игроков проверить реальную доставку на разные почтовые сервисы,
верный/неверный/просроченный код, существующий Baller ID, новый профиль,
возврат по приглашению и сохранение сессии на Android/iPhone.
У существующего игрока использовать прежний адрес, чтобы не создать второй аккаунт.

Ограничения:
- Настоящая доставка и живой вход этой сборкой ещё не проверены.
- Gmail — временный отправитель для пилота; Supabase предупреждает о доставляемости.
- Старый фрагмент видео про капитанские подтверждения сохранён с пояснением.
- 7 moderate-находок npm audit остаются в цепочке инструментов ESLint/TypeScript.
- Рейтинги, дуэли, загрузка фото, логин Baller ID/пароль и PWA не добавлялись.

Браузерные тесты используют фиктивный example.supabase.co, имитацию доставки
и изолированный PostgreSQL. Это не подтверждение состояния рабочей базы.
При возврате к прежнему UI учитывать, что шаблоны Auth теперь содержат код,
а не ссылку; откат UI не откатывает настройки Supabase.
