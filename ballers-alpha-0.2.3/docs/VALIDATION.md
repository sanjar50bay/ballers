## Ограничения доказательств

PGlite — настоящие PostgreSQL-функции на реконструированной public-схеме, но auth.uid и роли в тестах смоделированы. Браузерный тест вызывает эти функции через подменённый HTTP-транспорт, а не через живой Supabase PostgREST. Google-вход синтетический. Живой проект, реальные аккаунты, email/push, реальные мобильные устройства и многосессионная нагрузка не проверены.

## Воспроизведение браузерного теста (необязательно)

Playwright устанавливается отдельно от зависимостей приложения. Сначала production build с:

```
NEXT_PUBLIC_SUPABASE_URL=https://example.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=placeholder-test-not-a-secret
NEXT_TELEMETRY_DISABLED=1
```

Запусти `npm run start -- --hostname 127.0.0.1 --port 3012`, затем `node tests/browser.test.mjs` при доступном Playwright. `PLAYWRIGHT_MODULE` может задавать путь к его `index.mjs`, `CHROMIUM_PATH` — к системному Chromium. Запуск только с фиктивными параметрами, без реальных ключей.
