# Обновление 0.2.1: кликабельные разделы

## Для твоего BALLERS Test, где уже есть 001 и 002

1. Сохрани предыдущую папку и backup тестовой БД.
2. Выполни только `supabase/migrations/20261013_003_navigation_community.sql` в SQL Editor BALLERS Test. Полный текст одним запуском. **Не повторяй 001/002/baseline.**
3. Распакуй новый ZIP в отдельную папку. Перенеси свой тестовый `.env.local`, останови старый сервер Ctrl+C.
4. Из новой папки: `npm ci`, затем `npm run dev`.

## Что исправлено

- Home / Communities / + / Career — настоящие ссылки. Communities показывает твои сообщества; плюс предлагает создать сообщество или игровой день в сообществе, где ты менеджер. Career показывает твою историю и подтверждённую статистику, тесты отмечены отдельно.
- «•••» в сообществе открывает меню: все игровые дни, список сообществ, настройки по умолчанию и приглашение. Настройки доступны менеджерам и не переписывают существующие игры.
- Invite Players создаёт приглашение **в сообщество**, а не на конкретный матч. Ссылка действует 7 дней, до 50 новых участников. Вход через Google, MEMBER без возможности присвоить OWNER/MANAGER. Ответ на игру остаётся отдельным действием.
- В карточках участников сообщества убрана ложная заглушка Rating 500.
- Кнопки базовых составов переименованы: «Запомнить команды как постоянные» и «Применить постоянные команды к этому дню». Вторая заменяет сегодняшние команды до первого матча; включает только Going. Отсутствующие сохраняются в базе.

Ссылка с localhost работает только на том же компьютере. Чтобы пригласить с телефона/другого устройства, приложение должно быть доступно с него; ссылка использует текущий адрес открытого приложения. Публикация и безопасный публичный релиз этим обновлением не выполнены.

Остальные ограничения alpha (не системный push, открытый экран оператора для завершения по времени, неполная локализация и аудит безопасности) остаются — смотри README.
