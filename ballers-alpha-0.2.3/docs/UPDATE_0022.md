# 0.2.2 — уведомления

Колокольчик на Home теперь открывает настоящий список уведомлений. При пустом списке — «Уведомлений пока нет». Кнопка списка больше не прячется за всплывающим уведомлением. Добавлены закрытие Escape, управление фокусом внутри диалога и очистка сообщений после выхода.

Новой SQL-миграции нет. Если уже установлены 001, 002 и 003, ничего повторно выполнять не нужно. Сохрани прежнюю папку; распакуй новую копию, перенеси тестовый .env.local, останови старый сервер и запусти npm ci / npm run dev в новой папке. Если 003 ещё не установлена — инструкция UPDATE_003.md.

Проверено 16 браузерных сценариев на изолированной SQL-базе, в том числе заполненный и пустой список на Home. OAuth/HTTP-транспорт синтетические, это не проверка живого Supabase.

## Веб-хостинг: технический путь, ещё не выполнен

Next.js можно разместить на Vercel, базу оставить в Supabase. В репозиторий не включаются .env.local, node_modules и .next. URL и publishable key добавляются как переменные окружения хостинга; service_role/Google Secret в клиент не добавляются. В Supabase Auth нужно настроить Site URL и разрешённые redirect URLs нового HTTPS-домена. Для того же Supabase-проекта Google OAuth callback остаётся callback проекта, а не адресом приложения.

Vercel Hobby ограничен личным некоммерческим использованием. При коммерческом использовании выбрать подходящий тариф или иной хостинг с разрешёнными условиями; бесплатность не обещается для коммерческого запуска.

Перед доступом извне: устранить известные риски прав чтения старой схемы и dev-зависимостей, ограничить доступ тестерам на уровне Auth/серверных прав, проверить OAuth на реальном домене. Скрытая ссылка сама по себе не закрывает регистрацию/API. Публикация на хостинг не добавляет push и фоновое окончание матчей.

Официальные источники: https://vercel.com/docs/plans/hobby ; https://vercel.com/docs/limits/fair-use-guidelines ; https://supabase.com/docs/guides/auth/redirect-urls .
